## AMD XRT

The backend is compiled against the XRT headers and links the user-space library `libxrt_coreutil` dynamically. XRT's
user-space code is licensed under the Apache License 2.0; its Linux kernel driver (`xocl`, `xclmgmt`) is licensed
under the GNU General Public License version 2. Neither is copied into or linked statically with this project; the
license file of the XRT installation (`<XRT>/license/LICENSE`) applies to your copy.

## AMD Vitis, Vivado, Vitis HLS and the Alveo U50 platform

Building the bitstream requires AMD's tool suite and the U50 platform. They are proprietary and are **not**
redistributed here; you install them yourself and accept AMD's license terms (the tool installer and the platform's
`license/LICENSE` file). Please check the terms yourself before you use them for your purposes or **redistribute a
bitstream you built**: a bitstream is generated by those tools against the platform and may be covered by those
terms. This repository therefore ships sources and scripts only and no bitstream.

The kernel sources include the Vitis HLS headers (`ap_int.h`, `ap_fixed.h`, `hls_stream.h`, `hls_math.h`), which come
with the Vitis installation and are not copied into this repository. The optional emulator build compiles the kernel
sources against these headers on your machine.
